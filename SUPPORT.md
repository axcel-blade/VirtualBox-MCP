# Support

## Getting help

1. Read the [documentation](docs/), especially [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
2. Search the repository's existing issues and discussions.
3. Ask a question in **Discussions → Q&A**.
4. Report a reproducible bug using the **Bug report** issue template.

## When asking for help, include

- your host OS and version,
- your VirtualBox version (`VBoxManage --version`),
- your Node.js version (`node --version`),
- the guest OS and the execution backend (Guest Control, SSH or WinRM),
- the structured error code returned (for example `GUEST_ADDITIONS_NOT_INSTALLED`).

Remove passwords, tokens and private keys before posting logs.

## Security issues

Do not report security issues publicly. See [SECURITY.md](SECURITY.md).
